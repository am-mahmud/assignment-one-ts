# Assignment One: TypeScript

## Assignment Overview

This assignment covers core TypeScript concepts: optional and rest parameters, union types and type narrowing, readonly tuples, interfaces, generics, OOP access modifiers, and Promises.

| # | Function / Class | Topic |
|---|---|---|
| 1 | `multiplyValue` | Optional parameter |
| 2 | `processInput` | Union type, type narrowing |
| 3 | `formatCoordinate` | `readonly` tuple |
| 4 | `concatenateArrays` | Generics, rest parameters |
| 5 | `getPopularCourses` | Interface, `filter` |
| 6 | `pluckValues` | Generics, `keyof` |
| 7 | `Employee` / `Manager` | Class, inheritance, `protected` / `private` |
| 8 | `validateAgeAsync` | Promise, `async/await` |
